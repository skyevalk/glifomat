# Глифомат

ASCII-редактор в браузере: картинки, видео и камера превращаются в символы, точки, линии или брайль. Дизеринг, анимированные эффекты, реакция на мышь, генеративные WebGL-слои и экспорт в PNG, SVG (вектор), видео и живой HTML-фон для сайта.

**Онлайн:** https://skyevalk.github.io/glifomat/

## Запуск на маке

1. Скачай проект: зелёная кнопка **Code → Download ZIP** на GitHub (или `git clone https://github.com/skyevalk/glifomat.git`).
2. Дважды кликни **`start.command`**. Откроется браузер с Глифоматом на `http://localhost:5173`.
   - Если мак ругается «не удалось проверить разработчика»: правый клик по `start.command` → **Открыть** → **Открыть**. Один раз.
   - Если просит установить инструменты командной строки — согласись, это нужно для `python3`.
3. Закрой окно терминала, чтобы остановить.

Камера работает и онлайн, и локально. Если просто открыть `index.html` двойным кликом, всё кроме камеры тоже заработает.

## Что умеет

| Раздел | Параметры |
|---|---|
| Источник | картинка / видео / камера, качество сэмплинга 320 · 480 · 720, формат кадра, фон |
| Стиль | Classic ASCII, Braille, Halftone, Dot Cross, Line, Particles, Claude Code, Retro Art, Terminal — у каждого свои настройки |
| Символы | 7 шрифтов, 10 наборов символов + свой, дизеринг Floyd–Steinberg / Bayer / Atkinson |
| Тон | яркость, контраст, сила дизеринга, дизер в тенях и светах, виньетка |
| Сетка | размер ячейки, интервал, непрозрачность, свечение |
| Цвет | серый, цвет исходника, Matrix, Amber, свой; инверсия |
| Эффекты | Noise Field, Intervals, Beam Sweep, Glitch, CRT, Matrix Rain + направление и скорость |
| Мышь | притяжение / отталкивание, сила, радиус, мягкость |
| WebGL-слои | до 3 слоёв: Lightning Rails, Atmospheric Folds, Network Dome, Ambient Starfield, Terrain Mesh, Topology Dots, Radial Burst; отдельно или через ASCII, под или над символами |
| Экспорт | PNG, PNG ×2, SVG, MP4/WebM, HTML-фон, JSON настроек |

Горячие клавиши: **пробел** — пауза, **двойной клик по ползунку** — сброс к значению по умолчанию.

## Структура

```
index.html        разметка
css/style.css     интерфейс
js/engine.js      движок рендера (без интерфейса) — его же вшивает HTML-экспорт
js/app.js         панель, слои, пресеты, экспорт
start.command     локальный запуск на маке
tools/build.py    однофайловая сборка в dist/glifomat.html
```
